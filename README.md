Here, we are building a tracking solar system with two digital servo motors used to move the solar panel in azimuth and elevation. The controller of these two motors is an Arduino Uno; the values of the azimuth and elevation are calculated by equations. These two angles of the hollow day were calculated by a Raspberry Pi to positioning the motors on the correct angles and the Longitude and Latitude are given to Raspberry Pi by Arduino given the data from GPS module and the day of the year given from the OS of the Raspberry Pi, and there is another task for the Raspberry Pi which is creating an IoT server that sends the state of the device to a monitor. Used Arduino to create a software watchdog timer that turn the solar panel to the default position if the Arduino doesn't receive any signal from Raspberry Pi and control the NEO-M8N-0-10 GPS module and give him its power and control the servo motors, but motors' power is external and add another feature that is turn the solar panel to the default position when the system end its schedule at end of daylight. If the GPS doesn't respond and doesn't give any location, set the default longitude to 31.1141 and latitude to 29.033 and make the Raspberry Pi make its calculation using the default values until the GPS respond my a location, then update the value. Change the elevation minimum to 20, elevation maximum to 45, park azimuth to 90, and park elevation to 20. Due to the low memory availability of Arduino, after Arduino forwards the data captured from the GPS module to the Raspberry Pi and Raspberry Pi sends an ACK to tell Arduino that the data was delivered correctly, don't store this data on Arduino. Let the Raspberry Pi send a "SET_TIME" command to the Arduino on startup, or have the Pi send the scheduledTime as a "delay from now" rather than "absolute time".  Send the GPS data and then let the loop() handle the transition back to IDLE when the ACK eventually arrives via processCommand(). In moveServos, you have a delay of 2000. This stops the entire program for 2 seconds. If you want the watchdog to stay active during a move, you might want to use a non-blocking timer for movement, though 2 seconds is generally acceptable for a solar tracker. The power source is a solar charger controller that connects the solar panel with a battery and has two terminals for a load. Finally, collect the voltage, current, and power produced by the solar cell, and how much is consumed by the components of the system, and collect all this data and store it day by day.
